What is certified

A certified answer is a figure and the four things that produce it

- id: C05
  lang: en
  area: collections
  difficulty: 1
  question: What was the collection rate for government
    customers for December 2025 bills?
  query:
    metrics: [collection_rate]
    where: ["customer.segment = 'government'",
            "time.month = DATE '2025-12-01'"]
  expect: {kind: value, value: 0.560764, unit: ratio,
           metric_version: 1.0.0}

Metric and version

Which definition, and which version of it.

Filters and grain

Which customers, which period, grouped how.

Value

Run through the layer, never typed from a report.

The value alone cannot be checked by a reviewer: 0.85 could be January or March, finance's ratio or the certified one. The version matters because a metric change (Day 1, session 3) changes the certified answer, and the set must be re-certified with it.

The questions Muhsi must refuse

A refusal is a right answer, and the set must test five kinds of it

Restricted

Names, national IDs or mobile numbers of customers.

Forecast

Next year's revenue: the layer holds facts, not predictions.

Not matured

May 2026's collection rate: its 30-day window has not closed.

Uncertified

Bills paid on time: only a draft metric fits.

Causal

"Why did complaints rise?": a figure is not a cause.

An assistant that answers everything looks good on answerable questions. Only must-refuse questions show whether it invents figures. Ask the room which refusal their own assistant would most likely miss; most say "uncertified", and Lab 3.3 shows why.

The candidates came from three analysts, as drafts. A rejected draft is not always a useless question: the on-time share and the largest-customer questions are good questions whose right answer is a refusal. Write them into the set as refusals.

Lab 3.1, step 3

A Hijri question about monthly facts certifies a labelling choice

  • Ramadan 1447 runs from about 18 February to 19 March 2026
  • Bills and monthly usage are dated on the first day of the service month
  • So "data in Ramadan 1447" counts the March 2026 service month
  • Complaints are dated by day, so "complaints in Rajab 1447" is exact
Say it in the question. The certified answer must state the convention, or two analysts certify different figures and both are right.

The calendar uses the Umm al-Qura conversion (hijridate). Question U12 in the set. Ask: would your managers expect Ramadan's usage to include the February days? If yes, the layer needs daily usage, which is a design decision, not a test decision.

Session 2

Which context helps

  • Design an ablation that changes one kind of context at a time
  • Score each variant with a fixed model and question set
  • Read the contribution of each kind of context by language and area
02
What Muhsi reads

Each certified metric carries three kinds of context for the assistant

Synonyms

In both languages: "collection rate", "نسبة التحصيل", "معدل التحصيل".

Description

"Paid within 30 days of the due date, net of disputes, bill-month cohort."

Examples

A question and its query, such as a fiscal-year filter written correctly.

Muhsi answers with a semantic query, not SQL; the layer computes the figure.

Open data/metrics/collections.yml and show the ai: block of collection_rate. The prompt is built by muhsi.prompt from certified metrics only. Answering with a semantic query is what makes the layer the single source: the model chooses, the layer computes, the role applies.

Lab 3.2, the design

Remove one kind of context at a time, and keep everything else fixed

1 · Fixthe model, the 60 questions, run 1
→
2 · Remove onesynonyms, or descriptions, or examples
→
3 · Re-scorethe same scorer, by language and by area
Takeaway. One change per run, so each drop in accuracy has one cause.

Press once per step. Ask what goes wrong if you remove two kinds at once (the effects mix) or change the model between runs (a new model explains everything). This is the oldest rule of experiments, applied to prompts.

How the labs run without a key

A recorded stand-in makes every figure reproducible; a free hosted model makes it real

Stand-in (default)

720 recorded replies: 60 questions, 4 contexts, 3 runs. Written from a stated error model in _tools/make_case_files.py.

Live (stretch)

QAMAR_MODEL_MODE=live and a free OpenRouter key: the same prompt to google/gemma-4-31b-it:free.

Free models change. Record the model name and the date beside any live figure.

Be explicit with the room: the stand-in is not a model; it replays replies designed to show the failure kinds the session is about. Nobody should quote 95% as Muhsi's accuracy. The live stretch shows how far a real free model is from it; results vary by day and by rate limits.

Session 3

A scoring harness

  • Score an answer by executing it and comparing with the certified value
  • Separate wrong but plausible answers from obvious failures
  • Write an evaluation report that a reviewer can re-run
03
Lab 3.3, step 1

Score the figure the manager sees, not the text of the query

  • Two different queries can give the same figure: a fiscal year as a label or as a date range
  • A reply may come in a code fence, as a sentence, or with a bad date: each is an outcome, never a crash
  • Numbers match within a stated relative tolerance (0.5%); group names match exactly
```json
{"metrics": ["collection_rate"], "by": [],
 "where": ["time.month = DATE '2026-03-01'"]}
```

Execution accuracy is the common measure in text-to-SQL work (Spider, BIRD): run the predicted query, compare the result. Here the layer runs it with the asker's role, so an answer the role may not see is an error, which is right.

Lab 3.3, step 2

Seven outcomes, and the two that reach decisions

OutcomeWhenRun 1
Rightthe certified figure, within tolerance50
Refused rightrefused a must-refuse question7
Wrong but plausiblehalf to twice the figure, or a valid wrong group2
Missed refusalanswered a must-refuse question1
Wrong, visibleany other figure0
Errorno JSON, the layer failed, nothing came back0
Refused wronglyrefused an answerable question0

The half-to-twice band is a convention, stated in muhsi.PLAUSIBLE; a stricter team might use 80 to 125%. What matters is that it is written down and the same for every run. A missed refusal counts with the plausible errors: the number it gives looks real.

Lab 3.3, step 4

Three answers nobody would notice on a slide

C13 · Riyadh

Read "Riyadh" as the Central region: 86.0% instead of 81.5%.

Q11 · Billing complaints

Counted all complaints: January 2026 instead of November 2025.

C15 · On time

Answered with a draft metric (73.5%) instead of refusing.

Each looks like a careful answer. Each fails a different safeguard: a field, a metric choice, a certification status.

C13: is it a model error, a missing synonym (Riyadh is a city of the Central region) or a missing field in the prompt (customer.city is listed)? Q11: the price change in October 2025 caused billing complaints in November; the network incident in January caused complaints in general. C15 is fixed on Day 4 by a guard that refuses uncertified metrics before the layer runs them.

Lab 3.3, step 3

A report is evidence only if a reviewer can re-run it and get the same number

uv run python harness/score.py \
  --variant full --runs 1
  • Hashes of every input: the set, the replies, the model, the metric files
  • The scorer's version, the tolerance and the plausible band
  • The mode, and the model name and date when live
First thing to compare when numbers differ: the hashes, before any code.

The harness is a PEP 723 script: its dependencies are written in its header, so uv can run it anywhere. This is the capstone's reproducibility evidence (10 points): an assessor re-runs five questions during the defence.

Checkpoint

Same accuracy, different risk

Two assistant configurations both score 90% on the certified set. In A, the misses are errors and wrong refusals. In B, the misses are wrong but plausible figures. Which do you put in front of managers, and why?

Either: the accuracy is the same
B, because it always gives a number
A, because its failures are seen and re-asked; B's reach decisions
Neither until accuracy is measured on live traffic
Why. An error costs a second question; a plausible wrong collection rate costs a decision. Report both rates, not accuracy alone.

Answer: C. Day 4's routing policy uses exactly this: a tolerance for wrong figures, not for errors.

QuestionsFound by

The stable-wrong three are the plausible errors of Lab 3.3: C13, C15 and Q11. The unstable five are all difficulty 2 or 3.

Lab 3.4, step 5 and the stretch

A cache hides instability; a vote of three does not fix it

Cache run 1

All five unstable questions were right on run 1: a cache shows them stable and right, while a fresh ask sometimes is not.

Majority of three

56 of 60 right against 57 with run 1 alone: C09 is wrong in two runs of three, so the vote picks the wrong one. Triple the cost.

A cache is still useful for cost and consistency, but measure stability before caching, and re-measure when the model changes. A vote helps only when the right answer is the most common; for C09 it is not. The fix for C09 is an example for fiscal quarters, from Lab 3.2.

Checkpoint

A vendor's single run

A vendor reports 96% accuracy from one run at temperature zero on your certified set. What do you ask for before trusting it?

A larger question set
Three runs per question: the agreement rate and the stable-wrong questions
Nothing: temperature zero makes it deterministic
A run at a higher temperature
Why. One run hides instability and cannot separate a stable wrong answer from a lucky one.

Answer: B. Then ask which of the stable-wrong questions are wrong but plausible, and what the vendor changes when the model version changes.

Day 3 · Wrap-up

Three things to keep

Certify the query

Value, metric and version, filters, grain; every area, difficulty and language; refusals.

Change one thing

Ablate one kind of context at a time and read the column that matches your users.

Count the plausible

Report wrong-but-plausible and stable-wrong beside accuracy, in a report anyone can re-run.

Ask each table: which of the three stable-wrong answers would have reached your executive committee, and through which report?
